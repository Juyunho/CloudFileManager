## 技術契約

- 目標 .NET 10，依本機 SDK 10.0.401；Console 與記憶體模型，不依賴雲端或資料庫服務。
- 內部大小用非負 64-bit 整數 bytes，不使用浮點累加。顯示沿用題目的 KB/MB 拼字，但明示二進位語義。
- 建立時間在題目未指定，示範使用固定 UTC 時間並標為示範值（ROLE_DECISION）。
- 副檔名可帶點或不帶點，不區分大小寫，空值拒絕；結果依建立順序 DFS（ROLE_DECISION）。
- 同層名稱採 Ordinal 唯一；名稱不能含路徑分隔符；parent 不允許外部修改。未要求檔案移動或刪除。
- XML 是展示格式，非可逆保存格式；建立時間仍在模型與 Console 可見，XML 依題目僅顯示其指定屬性。
- Bonus 排序、編輯、多重標籤、Undo/Redo、GUI、持久化均未納入。
- GitHub origin 已確認，推送不屬於本輪本機實作 Gate。

## TEST 獨立計算要求

TEST 從原始 Word 第三節擷取檔名、數值與單位，形成獨立 fixture；以獨立換算邏輯逐筆計算，核對檔案集合與子目錄分組，再比較產品函式輸出。不得從產品 SampleTree 或產品換算函式取得預期值，也不得把先前聊天中的總數寫成常數。
